# 77 Birch Court, Unit 4 — Property Listing

A responsive, one-page static property listing website using the three original photos supplied with the request.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive styling and navy/gold theme
- `script.js` — accessible photo lightbox
- `assets/` — original supplied photos

## Preview locally
Extract the ZIP, then open `index.html` in a modern browser. The page uses a Google Fonts import when internet access is available; system serif/sans-serif fallbacks are included.

## Free hosting option
This is a static site and does not require a paid plan, domain purchase, or payment details. You can preview it locally without signing up for anything. If you choose to publish it, use a free static hosting plan and review the provider's current terms before proceeding. No hosting account or domain has been created by this package.

## Notes
- The photos are the original files provided; no stock photos were added.
- The supplied outdoor photo shows a paved outdoor dining area, so it is labeled “Outdoor space” rather than being represented as a balcony photo. The east-facing balcony is included as a stated property feature.
- No unprovided amenities, testimonials, neighborhood claims, or additional pages are included.
- The contact button uses the phone number provided in the request.
